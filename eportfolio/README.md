# Cybersecurity Principles ePortfolio

A six-page static site, ready for GitHub Pages.

## Files
- `index.html`: Home (name, photo, course, welcome, navigation)
- `about.html`: About me and optional résumé download
- `knowledge.html`: Three core topics, each with summary, examples, and an artifact
- `project.html`: Project showcase with the 500–800 word analysis
- `reflections.html`: Growth, challenge, and application reflections
- `references.html`: APA references with hanging indents
- `style.css`: All styling (light and dark mode, mobile layout)
- `images/`, `artifacts/`: Put your photo and artifact files here

## Filling it in
1. Find and replace "Your Name" in every file (it appears in the header, title, and footer).
2. Every amber, dashed-underlined passage is a placeholder (`<span class="fill">`).
   Replace the text AND remove the span so it displays normally. Search for `class="fill"`
   to confirm none are left before you submit.
3. Replace `images/headshot-placeholder.svg` with your photo and update the `src` and `alt` in `index.html`.
4. Optional: add `resume.pdf` to the main folder, or delete the résumé section in `about.html`.

## Publishing on GitHub Pages
1. Create a free account at github.com.
2. Create a new public repository (for example, `cyber-eportfolio`).
3. Click "Add file" > "Upload files" and drag in everything from this folder (keep the `images` and `artifacts` folders).
4. Go to Settings > Pages. Under "Build and deployment," set Source to "Deploy from a branch," Branch to `main`, folder `/ (root)`, and save.
5. After a minute or two, your site is live at `https://YOUR-USERNAME.github.io/cyber-eportfolio/`.
   Open it in a private window to confirm it works, click every link, then submit that URL to Canvas.

## Before you submit
- Every page reachable from the nav, every link works
- All placeholders replaced
- Images have descriptive alt text
- Project analysis is 500–800 words
- Every borrowed fact, image, or quote is cited in text and listed on References
