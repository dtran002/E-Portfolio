# E-Portfolio
This E-Portfolio highlights my knowledge, hands-on experience, and professional growth in cybersecurity as a Master's student at Old Dominion University. It showcases projects and coursework focused on network security, vulnerability assessment, firewall configuration, and cybersecurity principles. Through hands-on activities using tools such as pfSense, Nmap, and Metasploit, I gained practical experience identifying potential threats, analyzing network vulnerabilities, and implementing security measures. The portfolio also includes reflections on my learning experiences, challenges I overcame, and skills I continue to develop as I work toward my goal of becoming a cybersecurity analyst.
